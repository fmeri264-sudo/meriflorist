# Главная Мэри

Оформление: молочный фон #FAF7F2, графитовый текст #302C2E, малиновый акцент #793B55; заголовки Georgia, интерфейс Inter. Карточки товаров имеют пропорции 3:4.

Настройки главного баннера находятся в существующем разделе /admin/settings. Новые ключи SiteSettings: heroImageUrl, heroMobileImageUrl, heroImagePosition, heroTitle, heroDescription, heroButtonText, heroButtonUrl. Используется существующее хранилище key/value, миграции не нужны. Фото можно загрузить или указать URL; мобильное фото необязательно. Если главное фото не задано, показывается первое фото доступного основного товара.

Логотип продолжает загружаться из logoUrl в существующих настройках. По умолчанию используется новый горизонтальный логотип public/brand/mary-horizontal.png. В подвале — белая прозрачная версия. Загруженный администратором logoUrl сохраняет приоритет.

Главная: баннер → преимущества → поводы из Occasion → Выбор Мэри (8 основных товаров) → сезонный баннер (если задано фото) → категории → видимые HomeSection в установленном администратором порядке → О Мэри → процесс заказа → FAQ. Подборки, закрепления, лимиты, отзывы и страницы используют прежние данные и маршруты.

Проверка в облачной среде с Node.js 24: NODE_USE_ENV_PROXY=1 npm run dev. Переменная нужна только для работы через прокси среды; менять production-команду не требуется. Домен фотографий meriflorist.ru должен быть доступен сети среды. Не отключайте проверку TLS.

Известная исходная проблема production-сборки: PrismaClient не сгенерирован, ошибки в prisma/seed.ts и src/lib/db.ts. Схема Prisma требует отдельного исправления. Отзывы: node --import tsx tests/yandex-market-reviews.test.ts.

В разделе «Главная страница» есть ссылка на настройки баннера. Предпросмотр переключается между компьютером и телефоном до сохранения полей. Дополнительные настройки: homeSelectionTitle, homeSeasonalImageUrl, homeSeasonalTitle, homeSeasonalLink, homeAboutText, homeAboutImageUrl. Пустой homeSeasonalImageUrl скрывает сезонный баннер; пустой homeAboutText скрывает О Мэри. Фотографии задаются администратором; демонстрационные букеты в базу не добавлялись.
